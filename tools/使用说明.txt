CPE Monitor — 5G 通信壳 / 插卡路由器状态监视器
================================================

一个常驻菜单栏的小工具，实时看 5G 通信壳的工作状态。
支持三种设备后台，在设置里选「固件」即可切换：

  · project-cpe（默认，端口 3000）—— Rust/Axum 那套新固件，功能最全，不用密码
  · UDX710-TOOLS（端口 6677）—— 旧版工具后台，需要后台密码
  · 本地只读页（端口 9527）—— 只有系统信息和温度，看不了信号与速率


────────────────────────────────────────────────
一、怎么装
────────────────────────────────────────────────
1. 把窗口里的「CPE Monitor」拖到右边的 Applications（应用程序）文件夹。
   放进 /Applications 更好 —— 否则以后移动过它，「开机自启」会失效。

2. 第一次双击打不开是正常的（本版本没有 Apple 官方签名、未做公证）。
   任选一种方式放行：

   方式一（图形界面）：
     双击 — 提示被拦 — 打开「系统设置 → 隐私与安全性」，
     往下滚到「安全性」，点「仍要打开」，再确认一次。

   方式二（终端一行命令，任何 macOS 版本都有效）：
     打开「终端」，粘贴执行：
       xattr -dr com.apple.quarantine "/Applications/CPE Monitor.app"


────────────────────────────────────────────────
二、第一次运行：它会出现在哪
────────────────────────────────────────────────
这是个菜单栏常驻程序，**不会出现在 Dock 和启动台**。
启动后请看屏幕**右上角菜单栏**的天线条图标，点它展开面板。
面板右下角三个按钮：刷新 / 设置 / 退出。

首次启动会自动弹出一个窗口并停在「设置」页，就是让你填设备地址的。


────────────────────────────────────────────────
三、要填的连接信息
────────────────────────────────────────────────
先让这台电脑连上通信壳发出的 Wi-Fi，然后在设置页填：

  固件     先选设备刷的是哪套后台。选完端口会自动跟着填好。
           刷了 project-cpe 就保持默认，端口 3000。
  地址     设备的 IP。通常就是 Wi-Fi 的网关地址，
           常见的有 192.168.1.1 / 192.168.66.1 / 192.168.0.1。
           不确定的话看「系统设置 → 网络 → Wi-Fi → 详细信息 → TCP/IP」
           里的「路由器」地址，一般就是它。
  端口     project-cpe 是 3000；旧版 UDX710-TOOLS 是 6677；
           本地只读页是 9527。（USB 网卡直连时常见 192.168.66.1）
  后台密码 只有 UDX710-TOOLS 需要（一般是 admin）。
           project-cpe 没有登录接口，这一栏不会出现。

填完点「测试连接」；只有 UDX710-TOOLS 才有「验证登录」。
点「打开后台」能跳到设备的网页后台，顺便验证地址对不对。
UDX710-TOOLS 把「记住」开关打开，密码会存进 macOS 钥匙串，不用每次输。

⚠️ 只有 UDX710-TOOLS 的「实时下载/上传速率」需要密码；
   其余固件的数据都是直读的，所以就算密码不对，其他数据也会正常显示。

⚠️ macOS 15 及以上，第一次连接会弹一个
   「"CPE Monitor"想查找并连接本地网络上的设备」——**一定要点「允许」**，
   否则设备数据一条都拿不到。如果误点了不允许，
   去「系统设置 → 隐私与安全性 → 本地网络」里把它的开关打开。


────────────────────────────────────────────────
四、面板上能看到什么
────────────────────────────────────────────────
  运营商与制式   中国联通 / 中国移动 / 中国电信 / 中国广电 + 5G SA / 4G LTE + 频段
  签约状态       QCI 等级、签约上下行速率
  信号质量       RSRP / SINR / RSRQ，各带进度条与「极佳 / 良好 / 一般 / 较差」评级
  实时速率       下载、上传速度 + 最近 48 次采样的波形
  流量           剩余 / 已用、进度条、当日流量、设备总流量
  硬件状态       CPU 占用、内存占用、芯片温度、运行时长


────────────────────────────────────────────────
五、开机自启
────────────────────────────────────────────────
设置 → 开机自启 → 打开开关即可。
走的是系统「登录项」，想关掉的话在「系统设置 → 通用 → 登录项」里也能看到它。

提醒：如果之后重新构建/替换了这个 App，系统可能认不出旧的登录项记录，
      把开关关掉再打开一次就恢复了。


────────────────────────────────────────────────
六、几个已知事项
────────────────────────────────────────────────
· 手机和电脑必须连同一个 Wi-Fi（就是那个壳发出的热点）。
· project-cpe 固件的速率接口在设备端要同步采样 1 秒，所以刷新间隔
  设太小也不会更快；默认 2 秒已经够用。
· 「当日流量」是 App 在本机按秒累加出来的：设备端没有 vnstat（project-cpe）
  或 vnstatd 没在跑（旧固件）时，只能这么算。换设备后会自动归零重算。
  UDX710-TOOLS 的「当日流量」来自设备 vnstat 库，若 vnstatd 没跑，
  数字旁边会标注实际归属日期（例如「归属 9-11」），不会假装是今天的。
· 设备端是单线程 HTTP 服务，刷新间隔建议不要小于 2 秒。
· 设备维护：project-cpe 只提供「重启设备」；旧版 UDX710-TOOLS 才有
  「清理设备缓存」和「重置流量统计」。
· 演示模式：设置 → 高级 → 「离线演示模式」，不接设备也能看界面长什么样。
