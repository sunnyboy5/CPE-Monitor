CPE Monitor

菜单栏常驻的 5G CPE / 插卡路由器实时监控面板。
数据源为设备上运行的 UDX710-TOOLS HTTP 接口。

五个模块与数据来源

  • 网络信息 · 运营商、网络模式、频段、QCI、签约上下行 — GET /api/info
  • 无线信号 · RSRP / SINR / RSRQ 三项带评级与进度条 — GET /api/current_band
  • 实时网速 · 上下行速率 + 折线波形（48 个采样点滚动）— POST /api/netif/stats
  • 流量统计 · 套餐类型、本月、当日、累计 — /api/get/set + vnstat 明细
  • 硬件状态 · CPU、内存、芯片温度、运行时长 — GET /api/info

配色规范

  • 底色 #0D0D10，面板实色 #16161A，描边为白色 6%
  • 评级走冷色递进：极佳 #22D3EE → 良好 #60A5FA → 一般 #FBBF24 → 较差 #F87171
  • 下载 #60A5FA，上传 #A78BFA，不用发光与渐变底

与真实 App 的差异

  • 这是静态预览，数值是写死的示例数据，用来确认版式与配色。
  • 真实 App 里波形每 2 秒推一个采样点，进度条与评级随数据实时变化。
  • 字体用系统 SF Pro，与原生渲染一致；两侧留白与圆角已按 372px 面板宽度对齐。
